# Red-team findings

Three adversarial reviewers run at each unit of work and at each milestone gate: the security attacker, the confused first-time user, and the drift and truth auditor. They receive the code and the running app, not the builder's conclusions.

Severity: **blocker** (stops the milestone), **major** (fix within the milestone), **minor** (fix when convenient).
